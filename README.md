# CarCare

기존 `carcare.html`을 React 컴포넌트로 변환한 자동차 관리 웹앱입니다. 원본 HTML은 보존했습니다. Next.js App Router, TypeScript, Tailwind CSS, Lucide React, Recharts를 사용합니다.

V3 Gemini 서버 API·환경변수·무료 티어 보호·검증과 배포 절차는 [V3-RESULT.md](V3-RESULT.md)를 참고하세요. 키 없이도 V2 기능과 규칙 기반 도우미는 동작합니다. 실제 Gemini 실호출은 아직 검증하지 않았습니다.

## 실행

작업 폴더: `C:\car-care`

```powershell
npm.cmd install
npm.cmd run dev
```

개발 주소는 터미널에 표시됩니다(기본 http://localhost:3000).

```powershell
npm.cmd run lint
npx.cmd tsc --noEmit
npm.cmd test
npm.cmd run build
npm.cmd run start
```

브라우저 통합 테스트는 설치된 Google Chrome을 사용합니다. 프로덕션 빌드 후 실행하면 테스트용 서버를 3001 포트에서 시작합니다. 해당 포트에 다른 앱이 실행 중이지 않은지 확인하세요.

```powershell

```

## 데이터와 일관성

차량 관리 데이터는 현재 브라우저의 `localStorage`에 `carcare.v2`로 저장하며 로그인·서버 DB는 사용하지 않습니다. V3에서 사용자가 AI 요청 버튼을 누르면 선별된 자료만 서버를 거쳐 Google Gemini로 전송합니다. 브라우저 또는 접속 주소(origin)가 바뀌면 별도의 저장 공간을 사용합니다. 브라우저 데이터를 삭제하면 기록도 사라집니다.

서버 렌더링과 최초 hydration은 동일한 로딩 화면을 사용하고, 이후 클라이언트에서 저장 데이터를 읽습니다. 저장 성공 후 화면 상태를 변경합니다. 저장 실패는 화면·모달에 안내하며 미저장 변경을 적용하지 않습니다. 다른 탭의 변경을 수신하고 오래된 편집 데이터의 덮어쓰기를 막습니다.

같은 origin에 `carcare.v1`이 있으면 자동으로 읽어 새 데이터 형식으로 변환합니다. 기존 HTML을 `file://` 또는 다른 포트에서 열어 저장한 데이터는 브라우저 보안 정책에 따라 이 앱에서 직접 읽을 수 없습니다. 원본 키는 백업으로 남겨 두고, 새 앱의 전체 초기화는 v2 데이터를 초기화합니다. 손상된 데이터는 자동 삭제하지 않으며 복구 초기화 전에 확인합니다.

소모품의 유효 마지막 교체 거리는 **기본 교체 거리와 ID로 연결된 교체 이력의 주행거리 중 최댓값**입니다. 정비 이력의 추가·수정·삭제·연결 변경이 즉시 반영됩니다. 최신 교체 기록을 지우면 남은 기록 또는 기본 거리로 돌아갑니다. 기본 거리도 수정할 수 있으며 연결 기록보다 낮추어도 더 큰 기록은 계속 반영됩니다. 기존 v1의 lastKm은 수동 기준으로 보존합니다.

이름을 바꾸어도 ID 연결은 유지됩니다. 소모품 삭제 시 정비 이력과 비용은 남기고 연결만 해제합니다. 정비 기록의 큰 주행거리는 차량에도 반영하지만, 기록 수정·삭제로 현재 주행거리를 자동 감소시키지 않습니다. 현재 거리는 저장된 교체·정비 거리보다 낮출 수 없습니다.

거리 상태 기준: 남은 거리 1,000 km 초과는 정상, 0~1,000 km는 임박, 0 km 미만은 초과입니다. 진행률은 0~100%로 제한합니다. 월·연도는 사용 중인 브라우저의 현지 날짜를 기준으로 집계합니다.

교체 주기는 예시입니다. 제조사 설명서·운행 조건에 맞게 수정하세요. 브레이크액 등은 경과 기간 점검도 필요합니다. 기간 알림은 소모품의 `intervalMonths`가 1~240개월이고 기본 날짜 또는 연결된 교체 기록의 날짜가 있을 때 적용합니다. 최신 교체 날짜에 개월 수를 더하며 월말은 해당 월의 마지막 날로 보정합니다. 남은 기간 31일 이상은 정상, 0~30일은 임박, 음수는 초과입니다. 거리·날짜 중 더 시급한 상태를 적용합니다. 앱을 켠 상태에서 1분마다, 탭으로 돌아올 때 날짜를 다시 확인합니다. 앱을 닫았을 때의 푸시·백그라운드 알림은 제공하지 않습니다.

## V2 추가 기능

참고 파일은 `reference/carcare_ai_v2.html`입니다. 예상 견적의 8개 고정 예시 범위를 사용하며 실시간 업체 조회 또는 확정 가격이 아닙니다. 수량은 표시 단위(타이어 1개, 패드 1축 등)를 기준으로 부품비와 공임 모두에 적용합니다. 예정 견적은 `estimates`에 별도로 저장하여 정비 이력·교체 기준·비용 차트에 영향을 주지 않습니다. 실제 작업이 끝났을 때 **실제 정비 기록**에서 실제 비용을 직접 입력해 저장하면 그때 이력에 반영하고 예정 항목을 제거합니다. 저장 실패·취소 시 예정 항목은 유지됩니다.

증상 도우미는 `src/lib/v2.ts`의 키워드 규칙으로 동작하며 실제 AI 진단·고장 확정·운행 안전 보증이 아닙니다. 여러 규칙이 일치하면 화재·과열 등 높은 위험도를 먼저 안내합니다. 발생 상황은 참고 정보로만 표시하며 판단은 증상 텍스트를 사용합니다. 사진은 5MB 이하 JPG·PNG·WebP·GIF 미리보기만 지원하고 분석·업로드·localStorage 저장을 하지 않습니다. 증상 입력과 결과도 영구 저장하지 않습니다.

저장 키 `carcare.v2`와 `version: 2`는 유지합니다. `baseDate`, `intervalMonths`, `estimates`는 선택 필드이므로 기존 v2 데이터는 그대로 읽으며 읽는 것만으로 원본을 다시 저장하지 않습니다. 기존 v1 데이터와 V2 참고 HTML의 `lastDate`·`intervalMonths`도 읽습니다. 기간을 임의로 켜거나 과거 교체 날짜를 추정하지 않습니다. 개월 수만 있고 유효한 교체 날짜가 없으면 ‘날짜 미설정’으로 안내합니다. 기존 저장 오류 처리와 탭 동기화는 유지합니다.
